# 🌐 AutoTranslator — Умный десктопный автопереводчик

Компактное фоновое десктопное приложение на Python для мгновенного перевода текста прямо в поле ввода любой программы (Telegram, браузеры, текстовые редакторы, Discord, Word, IDE и др.).

---

## ⚡ Как это работает

1. Вы кликаете в **любое** поле ввода в любой программе Windows.
2. Нажимаете **`Ctrl`** — прямо рядом с курсором всплывает элегантное компактное окно в тёмной теме.
3. Вводите текст на русском языке.
4. Текст **в реальном времени** автоматически переводится на выбранный целевой язык и отображается в поле предпросмотра.
5. Нажимаете **`Enter`** (или кнопку «Вставить») — переведённый текст автоматически вставляется в ваше исходное поле ввода!
6. Если передумали — клавиша **`Esc`** моментально закрывает окно без вставки.

---

## 🚀 Основные возможности

- 🎯 **Глобальный перехватчик клавиш**: работает в фоне через `pynput` / `keyboard`. Не блокирует стандартные сочетания клавиш (`Ctrl+C`, `Ctrl+V`, `Ctrl+Z`).
- 📍 **Умное позиционирование**: окно открывается точно рядом с курсором мыши с контролем границ монитора.
- 🔄 **Реальный автоперевод «на лету»**: асинхронный перевод с технологией *debouncing* (300 мс) и кэшированием — интерфейс никогда не зависает.
- 🛡️ **Отказоустойчивость и Fallback**: использует `deep-translator` (GoogleTranslator). При сетевых ограничениях или ошибках `429 TooManyRequests` автоматически переключается на резервный провайдер `MyMemoryTranslator`.
- 🌍 **Мультиязычность**: удобный выпадающий список целевых языков (Английский, Немецкий, Французский, Испанский, Итальянский, Китайский, Японский, Турецкий, Польский, Португальский, Арабский, Русский).
- 🎨 **Современный тёмный UI**: выполнен на `tkinter`, минималистичный frameless-дизайн, тёмная тема (`#18181b`), подсветка синтаксиса и статусов, поддержка перетаскивания за шапку окна.
- 💾 **Локальная история переводов (SQLite)**: все переводы автоматически сохраняются в базу данных `history.db`. Встроенное окно истории с поиском, фильтрацией и копированием.
- 📌 **Иконка в системном трее (`pystray`)**: быстрый вызов переводчика, открытие истории, переключение режимов активации и смена языка из трея Windows.

## 🛠️ Установка и запуск

### 1. Требования
- Python **3.10** или выше
- Windows 10 / 11

### 2. Клонирование / Переход в папку
```bash
cd C:\Users\matve\.gemini\antigravity\scratch\auto_translator
```

### 3. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
# Создание виртуального окружения (по желанию)
python -m venv venv
venv\Scripts\activate

# Установка библиотек
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python main.py
```
> **Совет для скрытого запуска без окна консоли**: переименуйте `main.py` в `main.pyw` или запускайте командой:
> ```bash
> pythonw main.py
> ```

## ⌨️ Управление и горячие клавиши

| Действие | Горячая клавиша / Способ |
| :--- | :--- |
| **Открыть переводчик** | Нажмите **`Ctrl`** (одиночный быстрый тап в любом поле ввода) |
| **Вставить перевод** | Клавиша **`Enter`** или кнопка «⏎ Вставить» |
| **Закрыть без вставки** | Клавиша **`Esc`** или кнопка «✕» |
| **Перенос строки в поле** | **`Shift + Enter`** |
| **Копировать в буфер** | Кнопка «📋 Копировать» |
| **Открыть историю** | Кнопка «🕒 История» или меню трея |
| **Перетащить окно** | Зажмите левую кнопку мыши на верхней полосе окна |

### Режимы вызова (настраиваются в трее или в `config.json`):
1. **Одиночный Ctrl (быстрый тап)** — срабатывает при нажатии и отпускании клавиши Ctrl, не конфликтует с сочетаниями `Ctrl+C`, `Ctrl+V` и др.
2. **Двойной Ctrl** — два быстрых нажатия Ctrl подряд (аналог поведения в DeepL Desktop).
3. **Ctrl на нажатие (мгновенно)** — открытие сразу при опускании клавиши Ctrl.
4. **Ctrl + Space** — классическая комбинация клавиш.

## 🌐 Обработка ошибок

- **Нет интернета**: индикатор предупреждает о недоступности сети («⚠️ Нет сети»). При восстановлении соединения перевод возобновляется автоматически.
- **Лимиты Google API (429 TooManyRequests)**: приложение прозрачно переключается на резервный сервис `MyMemory`, не прерывая работу пользователя.
- **Пустой ввод**: защита от пустых сетевых запросов и вставки пустых строк.
